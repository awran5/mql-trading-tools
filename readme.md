# MQL Trading Tools

**A collection of robust, high-performance indicators and tools for MetaTrader 4 & 5.**

This repository serves as a centralized codebase for my algorithmic trading projects. All tools are open-source and developed with a focus on code quality, performance optimization, and logical reliability.

## 🤖 AI-Augmented Development

This project represents a collaborative effort between human creativity and Artificial Intelligence.
* **Concept & Logic:** Derived from practical market experience and structure analysis.
* **Code Architecture:** Foundations and structural patterns were brainstormed with **Gemini**.
* **Optimization & Review:** Code refinement, cache optimization, and stress-testing were conducted in collaboration with **Claude (Opus)**.

This workflow ensures that every tool here is not just "written," but rigorously "reviewed" for logic errors and performance bottlenecks before release.
